# ข้อกำหนดรายหน้าของ Chumkosoft

ใช้ข้อกำหนดนี้ควบคู่กับ [ระบบออกแบบ](../DESIGN.md) ช่องข้อมูลด้านล่างคือเป้าหมายในการปรับหน้าและสิ่งที่จะตรวจ ไม่ใช่สถานะว่าได้พัฒนาครบแล้ว

| เส้นทาง | จอแรกและการดำเนินการ | กรณีที่ต้องตรวจ |
| --- | --- | --- |
| `/` | จุดเริ่มสำหรับเข้าใช้ระบบกับลิงก์คู่มือตามบทบาท | หน้าแคบและการเข้าคู่มือด้วยคีย์บอร์ด |
| `/guide` | เลือกบทบาทแล้วเห็นงานและขั้นตอนที่เกี่ยวข้อง | กลับมาที่หมวดที่เลือกและรูปคู่มือไม่โหลด |
| `/login` | เลือกวิธีเข้าระบบและเห็นสถานะการยืนยัน | รหัสผิด หมดเวลา และปิดการเคลื่อนไหว |
| `/unauthorized` | แสดงบทบาทปัจจุบันกับปุ่มกลับหน้าที่เข้าถึงได้ | ผู้ใช้ทั้งห้าบทบาท |
| `/dashboard` | งานค้างวันนี้ ห้องที่เช็กครบเทียบกับทั้งหมด คาบถัดไปตามบทบาท | ไม่มีคาบ ไม่มีภาคเรียน และมีคำขอค้าง |
| `/dashboard/attendance` | ห้อง วันที่ คาบ และสรุปรายชื่อพร้อมสถานะบันทึก | รายคาบ ประจำห้อง เข้า–ออก บันทึกไม่สำเร็จ และสลับมุมมอง |
| `/dashboard/timetable` | ภาคเรียนและมุมมองห้องหรือครูบนตาราง | จอแคบ ตารางว่าง คาบชน และทางเลือกให้แก้โดยไม่ลาก |
| `/dashboard/students` | ห้อง ภาคเรียน ค้นหา และจำนวนผลพร้อมสถานะรายแถว | ตัวกรองว่าง มีหลายผล และกลับจากรายละเอียด |
| `/dashboard/students/[id]` | ชื่อ ห้อง สถานะ และทางไปข้อมูลเข้าเรียนหรือผู้ปกครอง | เปิดตรง เปิดผ่านกล่อง และชื่อยาว |
| `/dashboard/teachers` | ประเภทบุคลากร ความพร้อมบัญชีและบทบาทที่ดูแล | ผู้ดูแลกับครูเห็นการจัดการตามสิทธิ์ |
| `/dashboard/teachers/[id]` | ตำแหน่ง บัญชี และหัวข้อข้อมูลแยกตามงาน | เปิดตรง เปิดผ่านกล่อง และข้อมูลขาดบางช่อง |
| `/dashboard/classrooms` | ภาคเรียน ห้อง ครูที่ปรึกษา และจำนวนสมาชิก | ห้องไม่มีครูที่ปรึกษาหรือไม่มีนักเรียน |
| `/dashboard/classrooms/[id]` | ห้อง ครูที่ปรึกษา รายชื่อ และปุ่มเช็กชื่อหรือตาราง | เปิดตรง เปิดผ่านกล่อง และไม่มีรายวิชา |
| `/dashboard/courses` | กลุ่มสาระ รายวิชา และรายการที่เปิดในภาคเรียน | กรองแล้วไม่พบผล และทางเข้าตารางสอน |
| `/dashboard/rooms` | รายการสถานที่แยกตามประเภทพร้อมสถานะ | ค้นหาแล้วไม่พบและห้องถูกใช้อ้างอิง |
| `/dashboard/guardians` | แยกสถานะบัญชีเว็บและ LINE พร้อมความสัมพันธ์กับนักเรียน | หลายบัญชีต่อคน และผู้ปกครองหลายบุตรหลาน |
| `/dashboard/kiosk` | เครื่องที่ต้องตรวจ การติดต่อ ผลรับบันทึก และทางไปบัญชีหรือเครือข่าย | ออนไลน์แต่ไม่ได้บันทึก บัญชีปิด และเครื่องยังไม่ติดต่อ |
| `/dashboard/faces` | สถานะข้อมูลใบหน้าที่ระบบใช้งานได้กับที่ต้องดำเนินการ | ถอนได้นโยบายความยินยอมตามสิทธิ์ และไม่มีข้อมูล |
| `/scanner-devices` | แยกเครื่องที่ต้องตรวจจากเครื่องที่พร้อม แต่ละเครื่องเห็นการติดต่อ ผลบันทึก และโหมดจอ | ZKTeco ไม่มีข้อมูลคิว แอปรายงานคิว และเครื่องหยุดรับ |
| `/scanner-devices/zkteco` | เปิดหน้าจุดสแกนที่รายการ ZKTeco | ลิงก์เดิมและสิทธิ์ |
| `/scanner-devices/pin-mappings` | พาไปการจัดการเครื่องปัจจุบัน | ลิงก์เดิมและสิทธิ์ |
| `/pair-scanner/[code]` | รหัสยืนยันการเชื่อมโปรแกรมและปุ่มยืนยันบนมือถือ | หมดอายุ ใช้ซ้ำ และรหัสผ่านผิด |
| `/kiosk/login` | QR เป็นจุดหลัก รหัสผ่านเข้าถึงได้ | สร้าง QR ไม่ได้ หมดอายุ และสถานะรอยืนยัน |
| `/kiosk/confirm/[code]` | รหัสบนจอและผลยืนยัน เทียบได้ง่ายบนมือถือ | บัญชีจุดสแกนถูกปิดหรือรหัสหมดอายุ |
| `/scan` | สถานะเข้า–ออก ชื่อ เวลา และรายการก่อนหน้าตามค่าจอ | พักจอ หลุดเชื่อมต่อ ชื่อยาว และการซ่อนข้อมูล |
| `/dashboard/line` | สถานะการเชื่อมบัญชีและทางไปงานส่งหรือรายงาน | บัญชีที่ยังไม่เชื่อมและการส่งถูกพัก |
| `/dashboard/line-announcements` | ผู้รับ เนื้อหา และงานส่งล่าสุด | ยังไม่เลือกผู้รับ ผลส่งบางส่วน และการยืนยัน |
| `/dashboard/line/messages` | ช่วงเวลา ประเภทข้อความ ผล และรายการที่ต้องตรวจ | ไม่ทราบโควตา รายการล้มเหลว และตัวกรองไม่มีผล |
| `/dashboard/line/report` | ผลผูกบัญชีตามห้องพร้อมจำนวนที่ยังไม่ผูก | ห้องว่าง การกรอง และส่งออกรายงาน |
| `/dashboard/line/print` | ชื่อห้อง จำนวนใบ และตัวอย่างก่อนพิมพ์ | พิมพ์ A4 ข้อมูลหลายหน้า และ QR ที่พิมพ์จริง |
| `/dashboard/line/teachers` | แยกครูเชื่อมสำเร็จและรอเชื่อม | ไม่มีบัญชีหรือรหัสรอใช้ |
| `/dashboard/my-line` | ขั้นถัดไปของบัญชีตนเองพร้อมสถานะ | ยังไม่มีรหัส เชื่อมแล้ว และบัญชีเปลี่ยน |
| `/dashboard/behavior` | นักเรียน ยอดปัจจุบัน ผลหลังแก้ และประวัติ | เพิ่ม ลด เลิกแก้ และบันทึกไม่สำเร็จ |
| `/dashboard/emergencies` | งานรอรับเรื่องอยู่เหนือประวัติพร้อมจุดเกิดเหตุและเวลาล่าสุด | ส่ง LINE ไม่สำเร็จ รับเรื่อง และปิดเหตุ |
| `/dashboard/leave-requests` | รายการรอพิจารณา นักเรียน เวลา และเหตุผล | อนุมัติ ปฏิเสธ และกลับจากรายละเอียด |
| `/dashboard/settings` | หมวดตั้งค่าและค่าที่ใช้จริง แสดงเวลาตั้งส่งเทียบกับผลส่งล่าสุด | ปีการศึกษา การแจ้งเตือน และหมวดบริหาร |
| `/dashboard/settings/records` | แยกบัญชีผู้ดูแลออกจากถังขยะ แสดงผลก่อนยืนยัน | กลุ่มข้อมูลทุกประเภท การกู้คืน และรายการอ้างอิงค้าง |
| `/portal` | ชื่อผู้เรียนและข้อมูลวันนี้ก่อนตารางเรียน | นักเรียน ผู้ปกครองหลายคนในบัญชี และข้อมูลไม่พร้อม |

ตรวจโครงเว็บ แถบนำทาง กล่องรายละเอียดสามชนิด และสถานะโหลด ข้อผิดพลาด และ 404 เพิ่มเติมทุกครั้งที่คอมโพเนนต์ร่วมเปลี่ยน ปิดงานแต่ละกลุ่มเมื่อมีผลตรวจหน้าจอและขั้นตอนใช้งานจริงของกลุ่มนั้น
